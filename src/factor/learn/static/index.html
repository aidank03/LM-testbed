LESSON 03

PyTorch and JAX share the same idea

Both tools turn arrays into gradients. Their style differs, but the learning loop stays the same.

PyTorch

weight = torch.tensor(0., requires_grad=True)
loss = (weight * x - y).square().mean()
loss.backward()
weight.data -= 0.1 * weight.grad

JAX

def loss(weight, x, y):
    return jnp.mean((weight * x - y) ** 2)

gradient = jax.grad(loss)(weight, x, y)
weight -= 0.1 * gradient
